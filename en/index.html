How I build

01

Arabic is not a translation layer

Native RTL from day one. Arabic fonts loaded by PostScript name per weight, and Arabic copy written in Arabic — not translated from English.

02

Domain rules the libraries don't have

Gold in karats and grams, never ounces, because that is how it is actually bought here. Every entry locked to its exchange rate on the day it was made, so last year's numbers can't be rewritten.

03

Decisions get measured, not guessed

This accent measures 9.9:1 on the dark surface and 2.0:1 on white — which is why every surface on this page is dark. The 3D library was rejected on a number: 544KB gzipped before the scene itself.

04

Secrets stay on the server

No API key ever ships in a client bundle. Sensitive calls all run from Edge Functions, and the anon key has never seen a key.
